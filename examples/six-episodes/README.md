## 结果边界

图中的“突发变响”只表示相对近期语音的局部音量抬升，不等于爆响或惊醒次数。重叠窗口可能把短重音计为事件；尚未用主观听感校准。分数是六个指定片段之间的相对排名分，不是整档节目评分。
